📄 PDF Tools

PDF Merge और Image to PDF — सब कुछ आपके browser में, कोई upload server पर नहीं।

✅ यह tool mobile और desktop दोनों पर चलेगा। बड़ी PDF files में थोड़ा समय लग सकता है।

1. PDF Merge

2 या उससे ज्यादा PDF files select करें। फिर Merge PDF दबाएं।

⬇️ Download Merged PDF
PDF files select करें।

2. Image to PDF

JPG, JPEG, PNG images select करें। हर image PDF के अलग page में जाएगी।

⬇️ Download Image PDF
Images select करें।

Tips

  • PDF merge में files जिस order में select होंगी, उसी order में merge होंगी।
  • Images PDF में convert होते समय portrait/landscape अपने आप set होगा।
  • अगर बहुत बड़ी files हों तो mobile में slow हो सकता है।
